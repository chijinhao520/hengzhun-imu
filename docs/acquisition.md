# 标定采集流程

本流程针对 IMU660RB / LSM6DSR，±8g、±2000°/s，姿态解算 200 Hz、日志 50 Hz。工具首版不自动识别其他芯片、量程或采样率。

## 采集前

1. 在用于采集的固件副本中将静态标定恢复为恒等值：加速度 bias=0，所有 scale=1。必须记录固件版本和参数状态，避免在已修正数据上再次拟合。
2. 明确传感器安装方向、驱动输出系和车体系。开机零偏处理及输出 yaw 的来源也要记录。
3. 上电后静置至少 5 秒，让姿态融合启动过程完成。采集期间固定量程、输出率和安装方式。
4. 输出 [规定的 11 字段](data-format.md)，检查连续 20 ms 时间戳。缺帧、重复或跨重启文件不能直接用于本工具的固定频率积分。

## 加速度计六面

依次让 +X、−X、+Y、−Y、+Z、−Z 朝上，每个朝向放稳后保持至少 5 秒。实际夹具应尽量水平，工具的朝向识别阈值不是机械对齐精度承诺。采集一个连续日志，移动过程由静止窗口检测排除。

```bash
python tools/imu_calib_fit.py sixface your-six-face.csv
```

拟合模型为 `corrected = (raw - bias) × scale`。检查六个方向是否齐全、静止窗口数量与拟合后模长残差。输出残差属于同一批拟合数据的自检，应另采数据验证。

## 陀螺 Z 轴比例系数

在板角与桌面放置唯一对齐标记，以“角对角”确定整圈，避免矩形边缘转 180° 后仍对齐造成半圈误计。

1. 对齐并静置至少 3 秒。
2. 缓慢逆时针整 3 圈，每圈约 5–10 秒；回到相同标记，静置至少 3 秒。
3. 缓慢顺时针整 3 圈，回到相同标记，再静置至少 3 秒。

```bash
python tools/imu_calib_fit.py yawscale your-yaw.csv:+3,-3
```

正负号必须与实际输出 yaw 的方向一致。工具依据连续展开的 yaw 平台拟合，原始 gyro 积分用于交叉检查；不是使用包在 ±180° 内的 yaw 直接计算。

结果输出比例系数和两段间的差。差值过大时先核对参考标记、启动阶段、旋转速度和零偏，不通过修改真实圈数来“调好”结果。

## X/Y 轴（实验入口）

`gyroscale file.csv:x:+3` / `gyroscale file.csv:y:+3` 使用对应轴原始角速度积分估计比例。首版只保留这个工具入口，没有随仓提供真实 X/Y 轴验收数据；快速转动与不合适的夹具会增大误差。

## 回填与独立验证

将结果回填到与采集坐标系一致的标定层。换板、换量程或换安装方式时重新确认参数适用性。

回填后另行采集六面复测、双向闭合和较长时间静置记录，记录温度、时长、重复次数、误差和异常。不能把“0.46% 样本内模长残差”改写成“姿态精度 0.46%”或“陀螺零漂”。本仓库未给出新实板验收结论。
