# 与 MSPM0 / Fusion 的接入关系

首版是离线标定工具，不含可直接烧录的固件。以下说明来自原 MSPM0G3507 实车工程，便于集成时核对职责。

## 数据处理顺序

```text
IMU 原始寄存器数据
  → 驱动安装方向补偿
  → 在驱动输出系应用六面 bias/scale 和陀螺 scale
  → 运行时陀螺静止零偏扣除、单位转换
  → 映射到车体系
  → 对 gyro 与 accel 应用相同调平旋转
  → FusionBias 偏置估计
  → Fusion 无磁力计姿态解算
  → 连续 yaw、pitch、roll
```

工具只产生静态比例及加速度计零偏参数。运行时上电零偏、调平、采样调度和数据有效性属于固件接入层；不能只拷一份数值表就认为整套处理已经接入。

## 坐标约定

静态标定常量定义在驱动输出系。建立调平矩阵时，采集的重力向量应先映射到与运行时相同的车体系。改变车头定义后，即使传感器芯片没有动，也应重新检查映射和调平；陀螺与加速度必须同步应用对应旋转。

原样机后来采用 X/Y 取反、Z 不变的车体系变换，这不应成为其他工程的默认值。上电调平以静置表面为基准，在斜坡上会把坡面当水平；需要绝对坡度的应用不能直接沿用这种假设。

## 硬件接入需要补齐

原校准函数等待 data-ready 收集样本，应增加总超时与明确失败返回，再用于独立可复用固件。运行阶段需要检查传感器掉线、数据冻结和帧龄；已校准不等于输入永远有效。验证时分别核对静置、三个轴的方向动作和慢速转动。

本仓库没有复制此接入固件，因此不声称已经在独立项目中修复或验收上述事项。驱动可从 [逐飞上游](https://gitee.com/seekfree/MSPM0G3507_Library) 获取，融合可从 [Fusion](https://github.com/xioTechnologies/Fusion) 获取，分别遵守它们的许可。

## 电赛工程引用

电赛仓库后续使用本仓库的固定版本或 commit 引用标定流程和工具，并保留自己的固件快照、安装映射和样机参数。独立标定工具的升级不会自动改动原比赛固件。
