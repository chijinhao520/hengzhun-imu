# 误差来源与能力边界

## 分层处理

| 来源 | 常见表现 | 本方案的作用 |
|---|---|---|
| 加速度计零偏 / 比例 | 六面模长与对称性不一致 | 每轴 bias / scale 拟合 |
| 陀螺比例 | 已知整圈旋转的角度闭合误差 | 双向已知旋转校准 Z 轴比例 |
| 陀螺零偏 | 静止时 yaw 逐渐变化 | 在接入层使用上电静止零偏校准与适当的在线估计 |
| 安装坐标错位 | 倾斜符号反了，调平后仍有残差 | 明确坐标变换顺序，在同一坐标系建立和应用矩阵 |
| 温度变化 | 偏置随温度变化 | 当前没有温度曲线；静止在线估计只能处理其中满足条件的部分 |
| 无绝对航向参考 | 长时累计航向误差 | 六轴方案本身不能保证绝对航向长期无漂移 |

六面模型没有拟合完整非正交矩阵。yawscale 用融合 yaw 平台求比例，机械对齐、姿态融合状态和静止平台质量都会影响结果。两段系数之差只是样例的一致性描述，不是统计置信区间或传感器规格。

## 关于 FusionBias

原整机使用第三方 FusionBias 的静止偏置估计。它依赖阈值与持续时间判断，而非真实的“静止传感器”。小幅慢转可能被当成偏置；运动中也不应假定它始终更新温漂。需要结合实际场景和参照数据验证阈值。

## 后续如何报告效果

分别报告标定样本内残差与独立样本误差，至少记录：固件和配置版本、量程、采样率、安装姿态、上电静置时间、温度范围、采样时长、重复次数、真实转角参考及单位。对比前后效果时保持同类条件，保留失败样例。

目前仅两份标定样例随仓公开；没有将“校准后测试”这个文件名当作已完成验收，也没有生成不存在的精度曲线或成绩。
