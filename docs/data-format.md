# 日志格式与样例来源

每条记录为 11 个逗号分隔的整数，没有表头。工具支持原串口软件 `[hh:mm:ss.mmm] Rx:` 前缀及部分断行重组；不保证任意串口乱码都能恢复。

| 序号 | 字段 | 单位 / 定义 |
|---|---|---|
| 0 | ms | 设备启动后的毫秒时间戳；本版要求相邻记录严格相差 20 ms |
| 1–3 | acc_x / acc_y / acc_z | 驱动输出系的加速度计原始 LSB；±8g，4098.36 LSB/g |
| 4–6 | gyro_x / gyro_y / gyro_z | 同一驱动输出系的陀螺 LSB；±2000°/s，70 mdps/LSB |
| 7 | yaw10 | 连续展开的融合 yaw ×10，单位 0.1° |
| 8–9 | pitch10 / roll10 | 融合角 ×10，单位 0.1° |
| 10 | temp_c10 | 温度 ×10，单位 0.1°C |

历史解析器同时限制温度为 15–50°C、时间戳为 20 的倍数且小于 10^8 ms，并对载荷绝对值作 sanity 检查。它是针对这套历史格式的工具，不是通用长时间传感器日志读取器。

## 样例处理

两份样例来自项目自己的实板传感器采集记录：六面 2343 条、顺逆各三圈 4225 条。按原解析器恢复合法数值记录，保留顺序和全部数值，移除串口前缀、启动横幅及非记录字节；未插值、未平滑、未修改传感器数值。样例连续时间步长均为 20 ms。

仓库不包含原始串口日志的非数值内容。[manifest.json](../examples/data/manifest.json) 同时保存原记录 SHA256、导出数值文件 SHA256、原解析器 SHA256、记录数及转换说明。原始文件未随仓分发，所以这里能验证的是公开数值样例及结果，不能从本仓库重建被省略的非数值字节。

`parser_dropped_segments=0` 是原解析器的重同步计数，不表示原始文件没有任何杂字节。数据筛选方式已在上文明确。

## 参数与输出

`yawscale` 的路径参数从右侧拆分，支持 Windows 盘符。圈数必须是有限非零数值。拟合命令对缺面、平台数量异常、圈数不符和断续时间戳返回非零退出码。

静止窗口按 50 条记录组织。若采用其他采样频率，需要一起重新核对窗口长度、固定频率积分和动态阈值，不能只修改一个常数然后沿用当前验证结论。
